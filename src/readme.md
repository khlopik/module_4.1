# module_4.1_stm

Прошивка для мікроконтролера **STM32F411CE** (BlackPill) на Arduino + FreeRTOS.
Це перша половина пари **STM32 ↔ ESP32**: тут обробляються кнопки, енкодер і RGB-світлодіоди,
а ESP32 виконує свою частину. Контролери спілкуються між собою через UART.

## Модулі

| Модуль    | Файл                | Призначення                                  |
| --------- | ------------------- | -------------------------------------------- |
| `button`  | `button.cpp/.hpp`   | Зовнішня (PA6) та вбудована (PA0) кнопки     |
| `encoder` | `encoder.cpp/.hpp`  | Ротаційний енкодер, позиції 0…16             |
| `led`     | `led.cpp/.hpp`      | RGB-світлодіоди R/G/B та вбудований LED       |
| `uart`    | `uart.cpp/.hpp`     | Обмін повідомленнями з ESP32                 |

## Піни STM32

| Пристрій          | Пін          | Напрямок |
| ----------------- | ------------ | -------- |
| Зовнішня кнопка   | PA6          | вхід     |
| Вбудована кнопка  | PA0          | вхід     |
| Енкодер CLK / DT  | PA4 / PA5    | вхід     |
| LED R / G / B     | PA1 / PA2 / PA3 | вихід  |
| Вбудований LED    | LED_BUILTIN  | вихід     |
| UART TX / RX      | PA9 / PA10   | вихід / вхід |

Два серійні порти: `Serial` — налагоджувальний вивід через USB CDC,
`SerialVCP` (PA9/PA10) — робочий обмін з ESP32.

## З'єднання з ESP32

| STM32         | ESP32-S3       | Напрямок       |
| ------------- | -------------- | -------------- |
| PA9 (TX)      | GPIO16 (RX)    | STM32 → ESP32  |
| PA10 (RX)     | GPIO17 (TX)    | ESP32 → STM32  |
| GND           | GND            | спільна земля  |

## Протокол UART

115200 бод, 8N1, текстові рядки ASCII, роздільник — перевід рядка `\n`.

**STM32 → ESP32**

| Команда     | Значення                                     |
| ----------- | -------------------------------------------- |
| `R:<value>` | яскравість червоного каналу, 0…255           |
| `G:<value>` | яскравість зеленого каналу, 0…255             |
| `B:<value>` | яскравість синього каналу, 0…255              |
| `ON:1`      | увімкнути світлодіод на ESP32                  |
| `OFF:1`     | вимкнути світлодіод на ESP32                   |

**ESP32 → STM32**

| Команда   | Дія                                                |
| --------- | ------------------------------------------------- |
| `PRESS`   | кнопку натиснуто → увімкнути вбудований LED на STM32 |
| `RELEASE` | кнопку відпущено → вимкнути вбудований LED на STM32  |

## Логіка роботи

- **Енкодер** — кожен крок змінює яскравість обраного кольору. Позиція 0…16 перераховується
  у значення 0…255 (`поз. 1 → 15`, `поз. 16 → 255`), показується на RGB-світлодіодиках
  і надсилається ESP32, де встановлює яскравість відповідного кольору.
- **Зовнішня кнопка (PA6)** — перемикає колір R → G → B → R та синхронізує позицію енкодера
  з поточною яскравістю обраного каналу.
- **Вбудована кнопка (PA0)** — надсилає ESP32 `ON:1` / `OFF:1`, тобто вмикає або вимикає
  світлодіод на ESP32.
- **PRESS / RELEASE від ESP32** — вмикає або вимикає вбудований LED на STM32.

## Збірка

```bash
pio run             # збірка
pio run -t upload   # прошивання
pio device monitor  # монітор (115200)
```

Платформа: `ststm32`, плата: `blackpill_f411ce`, фреймворк: `arduino`.
Задачі FreeRTOS: `Check messages` (прийом), `Send messages` (передача), `Input` (кнопки та енкодер).
